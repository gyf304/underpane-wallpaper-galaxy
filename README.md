# underpane-wallpaper-galaxy

Stars and Galaxy wallpaper for [underpane](https://github.com/gyf304/underpane).

Shader: [Stars and galaxy](https://www.shadertoy.com/view/stBcW1) by [mrange](https://www.shadertoy.com/user/mrange), licensed CC0.

## Releasing

Push a tag — the `.github/workflows/publish.yml` workflow builds and uploads a
draft release containing `galaxy_<tag>.underpane.zip`.

```sh
git tag v0.1.0
git push origin v0.1.0
```
